# KINGDOM LUX

**Remote Lighting Control**

Commercial, proprietary lighting-control application focused on simple operation for church volunteer teams.

> Source availability in this repository does not grant an open-source license. All rights reserved.

## V1
- Windows first; Android and iOS planned
- Landscape-first UI for touch, mouse and keyboard
- grandMA2 simplified operation
- Operator and Configuration modes
- USB/Xbox-compatible gamepad control
- Bitfocus Companion integration planned
- Culto em Off branding

The first milestone uses a mock grandMA2 show so the operator experience can be built before connecting to a real console.
